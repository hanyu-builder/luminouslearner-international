Algebraic Resolution

Instead of drawing perfectly to scale, coplanar vectors can be mathematically resolved into mutually perpendicular X (horizontal) and Y (vertical) components.

1. Sum of X Components

Rx = Ax + Bx
Rx = 0

2. Sum of Y Components

Ry = Ay + By
Ry = 0

3. Resultant Vector (R)

Magnitude (Pythagoras):
|R| = √(Rx² + Ry²) = 0.00
Direction Angle (θ):
θ = tan⁻¹(Ry / Rx) = 0.0°
